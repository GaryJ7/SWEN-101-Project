GIT WORKFLOW COMMANDS

git status                 # Check working tree status.
git branch                 # List local branches.
git switch main             # Switch to main.
git pull origin main        # Update local main from GitHub.
git switch -c branch_name  # Create and switch to a new branch.
git add .                   # Stage all changes.
git commit -m "Message"     # Commit staged changes.
git push -u origin branch_name  # Push new branch to GitHub.
git push                    # Push commits to the current branch.
git fetch origin            # Download remote updates without merging.
git merge main              # Merge local main into the current branch. Use if out of date
git diff                    # View unstaged changes.
git diff --staged           # View staged changes.
git switch branch_name     # Switch to your feature branch.
git branch -d branch_name  # Delete a merged local branch.
git push origin --delete branch_name  # Delete a remote branch.

GITHUB PULL REQUEST:
Push your branch, then open a Pull Request on GitHub to merge it into main.

Steps to commit changes from branch to main:

1. Commit your work on your current branch
git add .
git commit -m "commit message"

2. Switch the main branch
git checkout main

3. Make sure your local main is up to date with GitHub's main branch by pulling
git pull origin main

4. Merge your branch with main
git merge <your-branch-name>

5. Push your updated local main to GitHub's main branch
git push origin main
